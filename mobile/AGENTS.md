# TidyNext no iPhone

Este diretório é o app nativo instalado pelo Xcode. A tela está em `html.js`, gerada na raiz com `npm run bundle:iphone`. Não publique um endereço.

No Mac, com o iPhone conectado:

```bash
npm install
npx expo run:ios --device
```

O identificador é `com.tidynext.home`. A câmera e a biblioteca pedem permissão só neste aparelho.
